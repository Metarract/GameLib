# IMPORTANT

#### Notes on Godot Nodes in this project

Nodes in this section will not show up in the Godot UI, whether they be labelled as a `GlobalClass` or otherwise. In order to use them, you will need to either provide passthrough versions within the actual project, or copy-paste them in.

Godot does not search for nodes outside of the main project - hence the requirement. _C'est la vie_
